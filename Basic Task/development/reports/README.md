# Reports — 项目报告

本目录用于存放 ANTLab Infra 基础阶段考核的项目总结、实验分析和测试结论。

## 1. 文件说明

| 文件 | 说明 |
|---|---|
| `final_report.md` | 最终考核报告，记录项目实现、运行环境、模型配置、性能测试结果、分析结论及当前局限。 |

## 2. 最终报告内容

`final_report.md` 主要包括以下内容：

1. **项目概述**：介绍本地大模型推理服务的建设目标、系统架构和请求处理流程。
2. **运行环境与模型配置**：记录硬件、操作系统、CUDA、llama.cpp 版本，以及模型文件、量化方式、SHA256 校验值和推理参数。
3. **服务实现**：说明 llama-server、FastAPI 接口、文件内容读取、Prompt 拼接和请求日志记录等功能。
4. **测试方法**：介绍单请求基准测试与不同并发级别下的性能测试。
5. **性能结果**：汇总请求成功率、平均延迟、最小/最大延迟、P50、P95 和吞吐量。
6. **结果分析**：比较不同并发级别下的吞吐量和延迟，讨论当前配置的性能表现。
7. **局限与改进方向**：说明重复测试次数、工作负载覆盖、Token 级性能指标、故障恢复验证和前端展示等方面仍存在的不足。
8. **复现说明**：提供模型服务、API 服务和基准测试的启动或执行方法。

## 3. 测试数据来源

报告中的主要性能数据来自以下文件：

| 文件 | 用途 |
|---|---|
| `tests/results/single.json` | 单请求基准测试结果 |
| `tests/results/concurrent.json` | 不同并发级别下的性能测试结果 |
| `results/requests.jsonl` | API 请求日志，用于追踪请求状态和延迟等信息 |
| `configs/baseline.json` | 基线服务与模型配置记录 |
| `configs/workload.json` | 测试工作负载配置记录 |

上述文件位于项目开发目录中。报告中的测试结论应以实际保存的结果文件和运行日志为依据。
